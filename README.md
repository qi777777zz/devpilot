# DevPilot

DevPilot is a multi-agent software engineering platform that turns repository-level requirements into traceable, tested code changes.

> Status: planning and initial setup.

## Planned capabilities

- Recoverable agent runtime with budgets, checkpoints, retries, and run traces
- Repository-aware code retrieval and context construction
- Multi-agent planning, implementation, testing, and independent review
- Sandboxed tool execution with patch validation and rollback
- Reproducible evaluation for task completion, cost, and reliability

The implementation will be developed incrementally, with measured results reported only after reproducible evaluation.
